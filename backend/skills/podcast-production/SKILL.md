# Podcast Production

Define the listener promise, episode structure, speakers, runtime, and key
takeaway. Build a natural spoken-word outline with a strong opening, clear
transitions, and a concise close. Flag claims that need fact-checking. When
writing a script, optimize for speech rather than essay prose.
