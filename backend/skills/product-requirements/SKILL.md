# Product Requirements

Create an implementation-ready product document.

Include the problem, users, goals, non-goals, functional requirements, edge
cases, success metrics, dependencies, risks, and testable acceptance criteria.
Separate confirmed requirements from assumptions. Prefer concise requirements
that use MUST for mandatory behavior and SHOULD for recommendations.
