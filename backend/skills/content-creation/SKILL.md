# Content Creation

Use this skill for public-facing editorial and marketing content.

1. Identify the audience, goal, channel, and desired action.
2. Lead with the useful idea instead of generic setup.
3. Keep claims specific and support factual claims with available evidence.
4. Match the requested channel and tone.
5. End with a clear next action only when the format benefits from one.

Return polished copy, not a discussion of the writing process.
