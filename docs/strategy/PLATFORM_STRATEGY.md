# Platform Strategy

This document is the source of truth for Kontext positioning.

## Product Line

### AmanCrawl

- Web intelligence infrastructure
- Search, crawl, scrape, browser automation, monitoring, extraction
- Audience: AI developers, RAG builders, agent builders

### AmanAgentLab

- Personal AI operating system
- Memory, artifacts, context, agents, MCP, workflows
- Audience: developers, founders, researchers, teams

## Positioning

- AmanCrawlshould be framed as infrastructure.
- AmanAgentLab should be framed as the personal AI OS.
- Kontext should be the persistent intelligence layer behind both.

## Messaging Shift

Before:

- Competing with Mem0

After:

- Competing with the memory category
- Creating the persistent intelligence category

Mem0 is a reference point.
The platform is the system.
