# Kontext Vision

This document is the source of truth for the long-term product vision.

## North Star

Kontext remembers what users know, understands what they are doing, and helps complete work over time.

Memory is foundation.

Context is product.

Autonomy is destination.

## Positioning

- Compete with the memory category
- Create the persistent intelligence category
- Treat Mem0 as a feature reference, not the destination

## Product Phases

### Phase 1

- Memory workspace

### Phase 2

- Knowledge system

### Phase 3

- AI assistant

### Phase 4

- AI worker

### Phase 5

- Personal AI operating system

## Product Boundaries

- The vision spans memory, artifacts, context, agents, workflows, and action-taking.
- Retrieval alone is not enough.
- Persistent continuity across sessions is a core requirement.
