# Memory Architecture

This document is the source of truth for the Kontext memory stack.

## Layers

### Layer 1: Facts

- User preferences
- Stable identifiers
- Reusable truths

### Layer 2: Artifacts

- PDFs
- Documents
- Repositories
- Reports

### Layer 3: Knowledge

- Relationships
- Topics
- Decisions

### Layer 4: Context

- Active project
- Current priorities
- Historical work

### Layer 5: Actions

- Research
- Summaries
- Analysis

### Layer 6: Workflows

- Weekly reports
- Monitoring
- Repository reviews

### Layer 7: Autonomy

- Continuous research
- Background agents
- Self-updating knowledge

## System Goal

Memory is storage.
Context connects the storage.
Intelligence comes from memory plus context plus actions over time.
