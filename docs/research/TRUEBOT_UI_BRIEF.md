# TrueBot interface brief

Build a separate hosted agent workspace at `/truebot` for authenticated TrueMemory users. Reuse the existing Stack Sans and Geist Mono fonts. A compact sidebar and a clear central work area use neutral surfaces, thin dividers and restrained amber emphasis. Utility and legibility define the visual direction; this workspace does not need decorative imagery.

Provide eleven destinations: Home, Chat, My Agents, Agent Templates, Tasks and Runs, Workspaces, Memory, Tools and Integrations, Automations, Usage and Limits, Settings. Agent configuration, real task submission, cancellation and persisted history are the primary workflows. Reuse existing workspace, memory, integration and account destinations where appropriate.

Read configuration and permissions from the authenticated backend. Never invent agent output, provider availability, usage or execution progress. Include useful empty states, loading, recoverable errors and disabled service states. Preserve ongoing run visibility across refreshes. Support narrow screens, keyboard navigation, visible focus and reduced motion.
