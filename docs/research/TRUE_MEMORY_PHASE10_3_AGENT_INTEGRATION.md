# Phase 10.3 Agent Integration

The universal contract is the existing provider-neutral operation set: search/retrieve, current state, timeline, related, store, update, forget, with REST, MCP, Python SDK and TypeScript SDK transports. Vendor adapters remain outside MemoryCore. Generic transport verification exists; named Claude Code, Codex, Cursor and OpenCode runtime integration remains NOT VERIFIED.

Agent identity and provenance must be carried as scope/agent_id, actor metadata, request id and source/provenance. No vendor-specific policy is added to the core.
